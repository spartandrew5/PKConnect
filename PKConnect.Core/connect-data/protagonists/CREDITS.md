# Trainer sprite credits

The sprite sets in this folder that come from the official games are Game Freak's work. The sets
below are fan-made, and are here with thanks to the people who drew or adapted them. Each set's
own `meta.ini` carries the same credit (`Creator` / `Adapter`).

Paths are `<character>/<generation>/<variant>`; a set can have front, back and overworld parts.

graphics collection of the Universal Pokémon Randomizer FVX, whose pack files name the same
artists.

If a set here is yours and the credit is wrong or missing, or you would like it removed, please
open an issue.
